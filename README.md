# Click Wisely! - QR Code Safety Page

This is the shorter version of the QR-awareness webpage for the 3D game **Click Wisely!**

## Structure

The page intentionally stays short:

1. Immediate hook after scanning
2. Four emphasized research statistics
3. One clear takeaway
4. One-question quiz
5. Research citation

## Files

- `index.html`
- `style.css`
- `script.js`

Open `index.html` in a browser, or upload the files to GitHub Pages.

## Source shown on the page

Sharevski, F., Mossano, M., Veit, M., Schiefer, G. & Volkamer, M. (2024).
*Exploring Phishing Threats through QR Codes in Naturalistic Settings.*
Symposium on Usable Security and Privacy (USEC).
